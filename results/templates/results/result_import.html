What happens

  • Students are matched on index number. An unknown index number is rejected, so import the students first.
  • A mock that already has results is skipped, never overwritten.
  • A blank or out-of-range mark is an error on that line only; the rest still import.
  • The preview shows each candidate's average and aggregate, so a transposition is visible before you commit.
  • Nothing is written until you confirm.
